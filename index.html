Kadmium

Distributed AI compute in Rust, with Lean 4 correctness proofs

  • Rust
  • Tokio
  • Lean 4
  • SafeTensors
View on GitHub ↗

Inspired by BOINC and CERN's computing grid, Kadmium splits transformer training and inference across mixed consumer and datacenter GPUs — with machine-checked proofs that the sharded result is identical to running on one machine.

  • Pure-Rust runtime for Llama, Mistral and Qwen models that streams only its assigned layers from SafeTensors, never loading the full model.
  • A planner assigns layers by each node's free VRAM and bandwidth, and re-routes work automatically when a node drops out.
  • Zero-sorry Lean 4 proof of partition equivalence, backed by Rust tests showing bit-identical output across cuts.

MCL4-COE & NCM

Custom LLM architecture, pretrained on a single 12 GB GPU

  • PyTorch
  • CUDA
  • Mixture-of-Experts
  • NVFP4
GitHub ↗ Hugging Face ↗

A language model family designed from first principles to train multi-billion-parameter models on consumer hardware. I've pretrained and published 2.43B and 1.77B parameter checkpoints.

  • MCL4 sparse attention: a Markov-chain local window plus global anchor tokens, for long context in linear memory.
  • A causal encoder-decoder Mixture-of-Experts backbone with nine specialized reasoning heads combined under a single softmax.
  • CPU-offloaded AdamW, activation checkpointing and NVFP4 2:4 sparsity to fit training into 12 GB of VRAM.

Mirror

  • UEFI

View on GitHub ↗

A freestanding kernel with multi-core scheduling, per-process memory isolation, a user-mode environment and real device drivers.

  • Per-process page tables with copy-on-write fork, demand paging and hardware protections (NX, SMEP, SMAP, UMIP).

  • VirtIO, AHCI and xHCI drivers, verified across 156 automated QEMU boot and fault-injection tests.
