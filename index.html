03 — Selected work

Things I've designed and built.

Electrace

EDA · in development

The electrical engineer's IDE.

A block-based, transparent schematic + PCB tool — nothing is a black box. Authored, versioned blocks compose into designs that are checked deterministically (real design rules, not simulation). I built the framework-agnostic TypeScript core (net derivation, power propagation, lint/DRC, KiCad export) and a custom SVG editor: schematic capture plus a KiCad-style PCB layout with octolinear routing, vias and multi-layer copper, filleted traces, a polygon board outline, design-rule checking, net highlighting, and a measurement tool.

  • TypeScript
  • Next.js
  • Custom SVG canvas
  • Deterministic DRC
  • KiCad export

OCB — Open Car Bus

Automotive · platform

Bus intelligence for the whole vehicle network.

Browse, search, decode, and generate code from CAN, CAN-FD, LIN, SENT, J1939 and OBD-II signal databases. Behind it is an automated ingestion pipeline — discover → AI-assisted preflight validation → sandboxed download → filter → dedup → provenance-tracked ingest — that pulls DBC, capture, firmware, and ECU-definition formats from across the web into a single queryable store.

  • Flask + REST
  • React / TypeScript / Vite
  • SQLite (20+ tables)
  • AI scraping pipeline
  • DBC · MF4 · BLF · VBF

RIND

CAD · generative

Upload an assembly, get an enclosure.

A web tool that takes a STEP model of an assembly — typically a PCB with connectors and components — and automatically generates a 3D-printable enclosure around it, with correctly placed cutouts for ports, screws, and features. A job queue drafts and reviews AI prompts, iterates on the generated geometry, runs QC against the original intent, and routes orders to in-house CNC and 3D printing. Upload → verify → ship.

  • STEP analysis
  • AI geometry generation
  • Job queue + QC loop
  • Stripe
  • R2 / Firebase storage
